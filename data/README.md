# Data

This project uses healthcare wait-time data from the Canadian Institute for Health Information (CIHI).

## Data Source

The dataset is publicly available from CIHI.

[Download the CIHI wait-time dataset](ACTUAL_CIHI_LINK)

## File Setup

The raw Excel file is not included in this repository.

After downloading the dataset, place the Excel file at:

`data/Raw Data/wait-times-priority-procedures-in-canada-2008-2025-data-tables-en.xlsx`

The analysis notebook expects this file path when loading the dataset.
